This is a [Next.js](https://nextjs.org) project.

## Getting Started

Run the development server from the `frontend` directory:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application. Edit `app/page.tsx` to change the home page.

## Testing

Run unit tests with `npm test` and coverage with `npm run test:coverage`. Cypress end-to-end tests can be run with `npx cypress run` after starting the development server.
